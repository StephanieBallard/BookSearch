# BookSearch

A simple iOS app built with SwiftUI that searches for books by title using the [Open Library API](https://openlibrary.org/developers/api).

## Features

- Live search with debouncing
- Displays book titles and authors
- Handles loading, empty and error states
- Cancels outdated search requests

## Built With

Swift, SwiftUI, MVVM and Swift Concurrency (`async/await`).
